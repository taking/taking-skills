# 기술 문서 제출 전 체크리스트

문서의 목적과 독자에 맞게 확인합니다. 모든 항목을 기계적으로 맞추지 말고, 해당하는 항목만 적용합니다.

## 구조와 흐름
- [ ] 문서의 목적과 범위가 처음에 드러나는가?
- [ ] 문서 종류에 맞는 섹션을 사용했는가?
- [ ] What, How, Why의 순서가 독자에게 자연스러운가?
- [ ] 각 섹션과 문단의 첫 부분에서 핵심 내용을 파악할 수 있는가?
- [ ] 제목만 훑어도 문서의 전체 구조를 이해할 수 있는가?
- [ ] 같은 사실을 여러 곳에서 반복하지 않았는가?
- [ ] 짝을 이루는 문서가 같은 개념에 같은 용어를 사용하는가?

## 문단과 줄바꿈
- [ ] 관련된 문장을 의미 단위로 묶었는가?
- [ ] 한 문장마다 빈 줄을 넣지 않았는가?
- [ ] 문단 내부에 편집기 폭 기준의 강제 줄바꿈이 없는가?
- [ ] 한 문단에 서로 다른 논점을 억지로 합치지 않았는가?
- [ ] 문단 길이를 기계적으로 제한하지 않았는가?
- [ ] 불필요한 빈 줄과 과도하게 잘게 나눈 소제목이 없는가?

## 정보 구조
- [ ] 배경, 판단 근거, 원인과 결과는 문단으로 설명했는가?
- [ ] 독립된 항목이 여러 개 나열될 때 Dash 목록을 검토했는가?
- [ ] 순서가 중요한 절차에 번호 목록을 사용했는가?
- [ ] 비교, 속성, 설정값, 계약은 표가 더 명확한지 검토했는가?
- [ ] 표를 사용했다면 같은 기준으로 비교하고 셀의 의미를 보존했는가?
- [ ] 목록 항목마다 하나의 핵심 내용이 있는가?
- [ ] 목록과 표를 사용한 뒤 논리적 관계와 조건이 사라지지 않았는가?
- [ ] 구조화가 오히려 읽기를 방해하는 곳은 일반 문단으로 되돌렸는가?

## 다이어그램
- [ ] 순서, 분기, 상호작용, 상태, 컴포넌트 관계를 다이어그램으로 표현하면 더 명확한지 검토했는가?
- [ ] 간단한 설명을 불필요하게 다이어그램으로 만들지 않았는가?
- [ ] Mermaid를 우선 검토하고 SVG는 필요한 경우에만 사용했는가?
- [ ] 노드, 레이블, 화살표 방향이 실제 동작과 일치하는가?
- [ ] 다이어그램과 본문, 표, 코드의 값이 일치하는가?
- [ ] 다이어그램으로 표현한 내용을 본문에서 반복하지 않되, 조건과 설계 근거는 남겼는가?

## 문장과 문체
- [ ] 행위 주체, 동작, 조건, 결과가 명확한가?
- [ ] 영어 어순을 그대로 옮긴 번역투가 없는가?
- [ ] 불필요한 수식어, 접속어, 반복 표현이 없는가?
- [ ] 모호한 표현을 구체화했는가? 근거 없는 구체화를 추가하지 않았는가?
- [ ] 가운뎃점, 긴 대시, 습관적인 부정 대구, 강조 분열문을 남용하지 않았는가?
- [ ] 요구, 제약, 계약 문장에 수준 키워드(MUST/SHOULD/MAY)를 명시하고, `~할 수 있다`를 허용의 뜻으로만 썼는가? ([reference/requirement-levels.md](reference/requirement-levels.md))
- [ ] 근거 없는 과장, 거짓 범위, 기계적인 3개 나열이 없는가?
- [ ] 기술 용어를 정확하게 유지하고 같은 개념에 같은 용어를 사용했는가?
- [ ] 자연스러운 문장을 스타일 규칙에 맞추려고 억지로 바꾸지 않았는가?

## 형식과 참조
- [ ] 모든 코드 블록에 적절한 언어를 지정했는가?
- [ ] H1은 하나이며 헤딩 계층을 건너뛰지 않았는가?
- [ ] 표, 목록, 코드 블록의 간격이 일관적인가?
- [ ] 내부 링크와 앵커가 실제로 존재하는가?
- [ ] 외부 표준과 명세의 참조 위치가 정확한가?
- [ ] 공식 제목, 고유명사, 코드 식별자를 임의로 바꾸지 않았는가?

## 기술적 정확성 (최우선)
- [ ] 기존 사실, 수치, 버전, API, 설정, 파일명, 순서를 보존했는가?
- [ ] 조건, 예외, 부정 표현 및 실패 동작을 빠뜨리지 않았는가?
- [ ] 구현에서 확인한 사실, 설계 의도, 추론을 구분했는가?
- [ ] 구현한 내용과 실제 검증한 내용을 구분했는가? 하지 않은 검증을 통과로 쓰지 않았는가?
- [ ] 확인되지 않은 동작이나 수치를 만들어 내지 않았는가?
- [ ] 표와 다이어그램이 본문 및 구현과 일치하는가?
- [ ] 모호한 부분을 추측으로 채우지 않고 확인 대상으로 남겼는가?

## 자동 검사

- [ ] 자동 검사 결과를 문맥에 맞게 확인했는가? 정규식 경고를 무조건 수정하지 않았는가?
