## 번역투 → 자연스러운 한국어

다음과 같은 영어식 표현이나 번역투를 그대로 옮기지 않습니다.

- "이것은 ~을 가능하게 합니다"
- "~을 수행합니다"
- "~을 제공합니다"
- "~을 지원합니다"
- "~할 수 있습니다"
- "~하는 데 도움이 됩니다"
- "~하는 것이 중요합니다"
- "~을 기반으로 합니다"

위 표현이 문맥상 자연스럽다면 사용할 수 있지만, 반복적으로 사용하지 않습니다. 다만 `~할 수 있다`가 명세의 허용(MAY)을 뜻할 때는 예외입니다. 이때는 줄이지 않고 그대로 씁니다([requirement-levels.md](requirement-levels.md)).

예를 들어:

나쁜 예:
> 이 기능은 설정 파일을 자동으로 생성할 수 있도록 지원합니다. 이를 통해 사용자는 설정을 쉽게 관리할 수 있습니다.

좋은 예:
> 이 기능은 설정 파일을 자동으로 생성합니다. 생성된 파일을 수정하면 필요한 설정을 바로 적용할 수 있습니다.

### 번역투 → 자연스러운 한국어 (더 많은 예)

규칙보다 대조가 빠릅니다. 아래 변환 패턴을 익힙니다.

| 번역투 / AI 문체 | 자연스러운 한국어 |
| --- | --- |
| 캐시를 사용함으로써 응답 속도가 향상됩니다. | 캐시를 쓰면 응답이 빨라집니다. |
| 이 값은 재시도 횟수를 나타냅니다. | 이 값은 재시도 횟수입니다. |
| 오류가 로깅됩니다. | 오류를 로그에 남깁니다. |
| 데이터의 검증이 수행됩니다. | 데이터를 검증합니다. |
| 설정을 로드한 후, 그리고 나서 서버를 시작합니다. | 설정을 로드하고 서버를 시작합니다. |
| 사용자는 토큰을 발급받습니다. 사용자는 그 토큰으로 인증합니다. | 토큰을 발급받아 인증합니다. |
| 다음과 같은 옵션을 제공합니다: retries, timeout | 옵션은 `retries`, `timeout` 두 가지입니다. |
| 보안을 위해 이 설정을 하는 것이 중요합니다. | 이 설정을 빼면 토큰이 평문으로 노출됩니다. |
| 이 기능은 단순한 캐시가 아니라 핵심 설계다. | 매 요청 재검증을 없애 응답을 20ms 줄입니다. |
| 확장성, 안정성, 유연성을 제공합니다. | (3개 맞춤 나열, 포장어 금지) 수평 확장과 무중단 배포를 지원합니다. |
| 전통부터 최신 기술까지 아우릅니다. | (실제 항목만) REST, gRPC를 지원합니다. |
| `~의 정수를 보여주는 중요한 전환점이다.` | (사실만) v2에서 인증을 OAuth로 바꿨습니다. |
| 요청이 큐에 저장되어진다. | 요청을 큐에 저장합니다. (이중피동 `~되어진다` → `~한다`) |
| 설계에 있어서 성능이 중요합니다. | 설계에서는 성능이 응답 지연을 좌우합니다. (`~에 있어서` → `~에서`) |

핵심 변환: **수동태 → 능동**, **명사형(~의 검증이 수행) → 동작(검증합니다)**, **"중요합니다" 선언 → 왜 그런지 직접 서술**, **주어, 접속어 반복 → 생략**.

### 한자어 동사 → 쉬운 동사

같은 뜻을 쉬운 동사로 전달할 수 있으면 굳은 한자어 동사를 쓰지 않습니다. 쉬운 표현이 정확성을 해치지 않을 때만 바꿉니다. 정확한 기술 용어(배포하다, 직렬화하다 등)는 그대로 둡니다. 상세 원칙은 [../style-guide.md](../style-guide.md) §8.4.

| 한자어 동사 | 쉬운 동사 |
| --- | --- |
| 생성하다 | 만들다 |
| 활용하다 | 쓰다 |
| 소요되다 | 걸리다 |
| 제거하다 | 없애다 |
| 존재하다 | 있다 |
| 확인하다 | 보다, 살피다 |
| 변경하다 | 바꾸다 |
| 추가하다 | 더하다, 넣다 |
| 반환하다 | 돌려주다 |
| 증가하다 | 늘다 |

## AI 문체 금지어

### 가운뎃점 `·`

나열을 `·`로 잇는 것은 AI가 쓴 글의 표시 중 하나입니다. **쉼표를 씁니다.**

| 쓰지 말 것 | 대신 |
| --- | --- |
| `설치·삭제·업데이트` | `설치, 삭제, 업데이트` |
| `Go·Java·Node` | `Go, Java, Node` |
| `요약 · 변경 · 영향` | `요약, 변경, 영향` (또는 표) |

셋 이상을 잇게 되면 쉼표로 늘리지 말고 표나 불릿으로 바꿉니다. 이미 굳은 고유명사와 문서 제목은 그대로 둡니다.

### 긴 대시 `—`

em-dash는 AI가 쓴 글의 대표 표시입니다. **마침표, 콜론, 괄호로 바꿉니다.** 상세는 [../style-guide.md](../style-guide.md) §8.1.

| 쓰지 말 것 | 대신 |
| --- | --- |
| `A한다 — B다` | `A한다. B다` (문장 분리) |
| `용어 — 설명` | `용어 : 설명` (앞뒤 공백 콜론) |
| `A — 부연 — B` | `A(부연) B` (괄호) |

예외 : 숫자 범위(`1-14`), 코드, URL, 표 구분선(`---`)은 하이픈이지 em-dash가 아닙니다.

### 부정 대구 (not X, but Y)

거부할 대상을 세웠다 치우는 수사입니다. 대개 뒤 절이 비어있습니다. 상세는 [../style-guide.md](../style-guide.md) §8.2.

| 쓰지 말 것 | 대신 |
| --- | --- |
| `단순한 X가 아니라 Y다` | 거부절을 지우고 Y를 구체적으로 |
| `X일 뿐 아니라 Y이기도 하다` | 실제로 하는 일을 직접 서술 |
| `이건 캐시 문제가 아니라 설계 문제다` | `스키마를 매 요청 재검증해서 느립니다` |

판정 기준 : 뒤 절(Y)이 수치나 동작으로 구체적이면 쓸 수 있습니다. 공허하면 거부절째 지웁니다.

### 강조 분열문

`중요한 것은 ~라는 점이다`, `핵심은 바로 ~`, `주목해야 할 점은 ~`처럼 강조 구문으로 문장을 비트는 패턴입니다. 상세는 [../style-guide.md](../style-guide.md) §8.6.

| 쓰지 말 것 | 대신 |
| --- | --- |
| 중요한 것은 캐시 무효화라는 점이다. | 캐시를 무효화해야 합니다. |
| 핵심은 바로 재검증 비용이다. | 재검증에 매 요청 20ms가 듭니다. |

판정 기준 : 강조 구문을 빼도 의미가 전달되면 핵심 내용을 바로 씁니다.

### 주어 없는 과장과 상투구

평가만 하거나 주어를 숨긴 채 부풀리는 상투 표현입니다. 실제 한 일, 주체, 사실과 수치로 바꿉니다. 상세는 [../style-guide.md](../style-guide.md) §8.3.

| 쓰지 말 것 | 대신 |
| --- | --- |
| 이 기능이 주목받고 있습니다. | 2026년 3월부터 사내 10개 팀이 씁니다. (주어와 사실 명시) |
| 캐시가 화제가 되고 있습니다. | 응답을 20ms 줄여 결제 팀이 도입했습니다. (누가 왜 쓰는지) |
| 이 모듈은 핵심 역할을 합니다. | 요청을 검증하고 라우팅합니다. (실제 한 일) |
| 메시지 큐로 자리매김했습니다. | 주문 이벤트를 전달하는 데 씁니다. |
| 안정성 향상에 기여합니다. | 재시도를 3회로 제한해 장애 전파를 막습니다. |
| 결론적으로 캐시가 중요하다는 것입니다. | 캐시로 재검증을 없애 응답이 20ms 빨라집니다. |
| 비용이 큰 셈입니다. | 매 요청 20ms가 듭니다. |

판정 기준 : 주어나 수치로 구체화할 수 있으면 그렇게 바꾸고, 근거를 확인할 수 없으면 과장 표현만 덜어냅니다. 없던 사실이나 숫자를 지어내지 않습니다. 확인이 필요하면 `[확인]`으로 남깁니다. `결론적으로 ~라는 것이다`식 상투 결론만 손보고, `~것이다` 어미 자체는 금지 대상이 아닙니다. 이 항목은 AI 탐지 신호가 아니라 가독성 기준으로 적용합니다.

### Elegant variation (유의어 바꿔쓰기)

같은 대상을 한 글 안에서 자꾸 다른 유의어로 바꿔 부르는 버릇입니다. 영어 작문은 같은 낱말 반복을 피하라고 가르치는데, 영어로 학습한 모델이 이 습관을 한국어에 그대로 가져옵니다. 한국어 기술 문서는 반대로 **같은 개념에 같은 용어**를 씁니다([../style-guide.md](../style-guide.md) §7).

| 쓰지 말 것 | 대신 |
| --- | --- |
| 컨테이너를 띄우고, 이 인스턴스를 등록하고, 해당 파드를 감시합니다. | 컨테이너를 띄우고, 그 컨테이너를 등록하고, 감시합니다. (같은 대상이면 같은 말) |
| 캐시는 빠르다. 이 저장소는 재검증을 없앤다. 해당 버퍼가 지연을 줄인다. | 캐시는 재검증을 없애 지연을 줄입니다. (한 대상을 한 이름으로) |

판정 기준 : 가리키는 대상이 같으면 같은 용어로 통일합니다. 서로 다른 대상이라 구분이 필요하면 바꿔 부르는 것이 맞습니다.

### 반복 표현

다음 표현을 필요 이상으로 반복하지 않습니다.

- `이를 통해`
- `~를 통해`
- `~에 대해`
- 또한
- 나아가
- 이와 더불어
- 이러한
- 기반으로
- 따라서
- 결과적으로
- 한편
- ~할 수 있습니다
- ~을 제공합니다
- ~을 지원합니다
- ~을 수행합니다
- ~하는 데 도움이 됩니다
- ~하는 것이 중요합니다
- ~라고 볼 수 있습니다
- 다음과 같은
- 이 문서에서는
- 살펴보겠습니다
- 알아보겠습니다
- `효율적으로`
- `원활하게`
- 강력한
- 유연한
- 간편하게
- 쉽게

이 표현들을 금지어처럼 기계적으로 제거하지 않습니다. 문맥상 필요한 경우 사용하되, **반복되는 패턴을 줄이는 것**을 목적으로 합니다.

접속어(`또한`, `따라서`, `나아가`, `이와 더불어`)와 `~를 통해`, `~에 대해`는 한 문단에 세 번 이상 몰릴 때만 손봅니다. 일부를 빼거나 `그래서`, `그런데`로 바꾸고, 한두 번은 그대로 둡니다.
