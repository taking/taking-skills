# typescript : TS, JS 주석 규칙

공통 규칙은 [common.md](common.md), 정본은 [../style-guide.md](../style-guide.md). 여기는 TS, JS와 React에서만 나오는 것만 적습니다.

## 목차

- 형식
- 반드시 문서화
- 적지 않을 것
- 예

## 형식

| 상황 | 형태 |
| --- | --- |
| 산문 설명 | `//`. `/* */`는 JSDoc(`/**`)이 아니면 쓰지 않습니다 |
| 공개 함수, 컴포넌트, 타입 | JSDoc `/** */`. 한 줄 요약이 먼저, 태그는 필요할 때만 |
| JSX 안 | `{/* */}`. 여는 태그 속성 사이에는 `//`가 들어가지 않습니다 |
| 타입 필드 | 필드 위 `/** */`. 에디터가 그 자리에서 보여줍니다 |

`@param`, `@returns`를 기계적으로 채우지 않습니다. 타입이 이미 말하는 것을 다시 적는 꼴이 됩니다. 설명할 것이 이름, 타입에 없을 때만 붙입니다.

```ts
// Bad: 타입이 말하는 것을 태그로 반복
/**
 * @param clusterId 클러스터 식별자
 * @param size 페이지 크기
 * @returns 자원 목록
 */

// Good: 타입에 없는 것만
/** `size`는 계약 상한이 100입니다. 넘겨 보내면 서버가 400을 줍니다. */
```

## 반드시 문서화

코드에서 안 보이고, 모르면 잘못 고치는 것들입니다.

| 상황 | 남길 사실 |
| --- | --- |
| 전역 CSS가 태그를 `!important`로 누름 | 왜 `span`, `h4`를 썼는지. 모르면 `p`, `h2`로 "정리"하고 화면이 깨집니다 |
| 생성 코드 | 재생성이 기준임을 생성물 경계에 한 줄(`src/generated`, `gen/` 등) |
| 계약 값 | 페이지 상한, enum, 응답 코드(202 접수 등). 화면이 그 값을 전제로 동작할 때 |
| 응답에 null이 오는 필수 필드 | 계약과 실제가 어긋나는 자리. 대체 키를 쓰는 이유 |
| `stopPropagation`, `preventDefault` | 무엇과 겹쳐서 막는지 |
| 의존성 배열에서 뺀 값 | 왜 뺐는지. 넣으면 무한 루프인지, 의도적으로 최초 값만 쓰는지 |
| `replace` vs `push` (라우팅) | 뒤로가기 동작이 달라집니다 |
| 디바운스, 폴링 간격 | 원천이 비싼 경로(터널, 외부 API)일 때 그 사실 |
| 접근성 우회 | `aria-label`이 겹치면 안 되는 이유, 초점을 못 받는 요소를 보완한 방법 |
| 브라우저, 라이브러리 제약 | 어느 브라우저, 어느 버전에서 무엇이 안 되는지 |

## 적지 않을 것

- 훅 이름을 풀어쓴 주석(`// 상태를 만듭니다` 위의 `useState`).
- JSX 구조 안내(`{/* 위: 검색 카드 */}`, `{/* 아래: 목록 */}`). 마크업이 이미 말합니다.
- 라이브러리 사용법. `docs/`나 링크로 보냅니다.
- 걷어낸 구현의 회고. 커밋 메시지가 갖습니다.
- UX, 디자인 근거. 화면 시나리오 문서로 보냅니다.

## 예

```tsx
// Bad: 마크업 재진술
{/* 위: 검색, 필터 카드. 검색이 폭을 차지하고 생성이 오른쪽 끝에 붙습니다 */}
<div className="flex ...">

// Good: 모르면 되돌려 깨뜨릴 사실
{/* globals.css가 `p`를 15px, weight 400으로 강제하므로 span에 둡니다 */}
<span className="text-xs">
```

```ts
// Bad: 결정 서사
// 검색어는 주소에 넣지 않습니다. 글자마다 주소가 바뀌어 이력이 더럽혀지고,
// 디바운스가 없는 지금은 조회까지 매 글자 나갑니다.

// Good: 명사형 한 줄
// 검색어는 주소에서 제외 (글자마다 이력이 쌓임)
```

```ts
// Good: 의존성 배열에서 뺀 이유
// `installedNames`를 넣으면 매 조회마다 effect가 다시 돌아 폴링이 멈추지 않습니다.
useEffect(() => { ... }, [settling])
```
